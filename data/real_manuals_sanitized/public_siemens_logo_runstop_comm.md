# 公开资料摘录：Siemens LOGO! 运行状态与通信状态

来源文件：`data/raw_manuals_downloaded/logo_system_manual_zh-CHS_zh-CHS.pdf`

来源页码：57-59、95

设备型号：LOGO! 0BA6

测试别名：PLCLOGO

## PLCLOGO RUN / STOP 状态

LOGO! 基本模块有 STOP 和 RUN 两种主要运行状态。STOP 时不读取输入、不执行电路程序，输出保持断开；RUN 时读取输入、执行电路程序，并驱动继电器或晶体管输出。

指示灯含义：

- 绿色：RUN。
- 红色：STOP。
- 橙色或黄色：扩展模块初始化或通信状态异常。

排查建议：

1. 先看 RUN/STOP 指示灯颜色。
2. 如果为 STOP，检查是否无程序、进入编程模式或程序未启动。
3. 如果扩展模块红灯，检查左侧模块通信和电源。
4. 如果输出异常，确认设备是否实际处于 RUN。

## PLCLOGO AS-i 通信异常

AS 接口模块通信状态可通过 LED 判断。绿色表示通信正常，红色表示通信失败，红色/黄色闪烁可能表示从站地址为 0。

处理建议：检查 AS 接口电源、从站地址、总线接线和模块位置。

## PLCLOGO EIB/KNX 总线异常

EIB/KNX 总线连接中断时可能出现红灯。总线短路或中断后，配置中可设置对应行为，通常需要检查总线接线和 ETS 配置。

## PLCLOGO RUN 到 STOP 的模拟量输出

从 RUN 切换到 STOP 时，模拟量输出可配置为保持最后值或切换到已定义值。排查模拟量输出异常时，需要核对 STOP 模式输出设置。
