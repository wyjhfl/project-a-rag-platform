# 公开资料摘录：Daikin / McQuay MicroTech II 冷水机报警资料

来源文件：`data/raw_manuals_downloaded/OM_780-3.pdf`

来源页码：108-118

设备型号：MicroTech II Chiller System Manager

测试别名：CW780

## CW780 报警监控

MicroTech II Chiller System Manager 会监控冷水机系统设备的报警条件。检测到报警后，系统会在状态界面显示 CSM Alarm，在 View Alarms 页面记录并等待确认，同时执行保护控制动作。

处理建议：先查看报警页面，确认报警类型、发生时间、相关设备编号和是否需要手动清除。

## CW780 报警清除

报警清除前必须先让导致报警的条件恢复正常。自动复位报警会在条件恢复后自动消除；手动复位报警需要操作员在界面上执行清除。

注意：如果传感器未安装但误设置为 present，可能产生不必要的传感器失败报警。

## CW780 无冷冻水流 No Chilled Water Flow

当泵控制选项启用时，如果所有冷却负载泵都被判定失败，会触发无冷冻水流报警。泵可能在数字输入打开而数字输出闭合持续超过检查延时时被判定失败。

处理动作：

1. 检查冷冻水泵运行状态。
2. 检查泵状态反馈输入。
3. 检查水流开关和相关接线。
4. 检查过滤器、水阀和管路是否造成流量不足。
5. 系统停机后，需要在用户界面手动清除报警。

风险提示：无水流报警发生后系统会立即停机并保持停机，不能只重启忽略流量原因。

## CW780 蒸发器水流未建立

启用冷水机后，如果蒸发器流量开关在等待时间内没有证明水流存在，会触发 No Evaporator Flow After Enabling Chiller X 报警。

处理建议：检查蒸发器泵、流量开关、阀门状态和对应冷水机编号；报警会让该冷水机不可用，直到在 CSM 界面手动清除。

## CW780 温度与压差传感器失败

回水温度、供水温度、回路压差和旁通管温度传感器读数超出范围时，系统会触发传感器失败报警。排查时应检查传感器接线、信号范围和是否正确设置 sensor present。
