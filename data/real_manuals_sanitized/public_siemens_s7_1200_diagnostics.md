## PLC1200 在线和诊断

S7-1200 入门手册说明，在线和诊断门户可用于与在线 CPU 交互，查看和更改 CPU 工作模式。

诊断入口：

1. 打开在线访问。
2. 选择在线 CPU。
3. 进入在线和诊断或在线工具任务卡。
4. 查看 CPU 当前工作模式、循环时间和存储器使用情况。

## PLC1200 RUN / STOP 状态

在线工具可以显示 CPU 工作模式，并通过操作员面板切换 STOP 或 RUN。RUN/STOP 指示颜色可用于判断 CPU 当前状态：黄色表示 STOP，绿色表示 RUN。

排查建议：

- 如果设备不运行，先确认 CPU 是否在 RUN。
- 如果 CPU 在 STOP，检查是否有人为切换、程序下载异常或硬件配置不一致。
- 查看在线诊断信息和循环时间，判断是否存在程序或资源异常。

## PLC1200 IP 与通信问题

下载 IP 地址前，应确认 CPU 的 IP 地址和子网掩码与编程设备兼容。多个 CPU 或 HMI 设备联网时，需要合适的以太网交换机。

排查步骤：

1. 确认编程设备与 CPU 在同一网段或路由可达。
2. 确认 CPU 的 IP 地址和子网掩码已经下载。
3. 检查交换机、网线和端口指示灯。
4. 使用在线访问查找 CPU。

## PLC1200 上传与硬件检测

如果有可连接的物理 CPU，可以从在线 CPU 上传代码块或硬件配置。硬件检测可用于识别连接设备，适合排查离线项目与现场 CPU 不一致的问题。
